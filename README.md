# 🤖 AI Resume Reviewer

An AI-powered desktop application built with **Python**, **Tkinter**, and the **Groq API** that reviews resumes and provides professional feedback.

---

## 📌 Features

- 🤖 AI-powered resume review
- ⭐ Overall resume score
- ✅ Highlights strengths
- ⚠️ Identifies weaknesses
- ✍️ Detects grammar issues
- 💡 Suggests improvements
- 💾 Save review to a text file
- 📂 Load previously saved review
- 🗑️ Clear review
- 🖥️ Simple and user-friendly Tkinter GUI

---

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Groq API
- Llama 3.3 70B Versatile
- File Handling

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Resume-Reviewer.git
```

### 2. Navigate to the project folder

```bash
cd AI-Resume-Reviewer
```

### 3. Install dependencies

```bash
pip install groq
```

### 4. Create a `.env` file

```env
GROQ_API_KEY=your_api_key_here
```

### 5. Run the application

```bash
python main.py
```

---

## 📖 How to Use

1. Paste your resume into the text box.
2. Click **Review Resume**.
3. Read the AI-generated feedback.
4. Save the review if needed.
5. Load previous reviews anytime.
